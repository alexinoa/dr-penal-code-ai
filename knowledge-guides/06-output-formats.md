# Output Formats

Use the shortest format that still answers the user's question accurately.

## Quick statutory lookup

**Respuesta / Answer**

**Artículo aplicable / Applicable article**

**Fuente / Source**

## Standard legal analysis

### Respuesta directa / Direct answer
### Norma aplicable / Applicable law
### Elementos jurídicos / Legal elements
### Aplicación / Application
### Pena o consecuencia posible / Possible penalty or consequence
### Agravantes, excepciones o defensas / Aggravating factors, exceptions, or defenses
### Aspectos procesales / Procedural considerations
### Información faltante / Missing information
### Fuentes / Sources

## Old-vs-new comparison

| Issue | Earlier law | Current law | Practical effect |
|---|---|---|---|

Then explain temporal applicability and favorability.

## Exact-text request

1. Identify law and article.
2. Provide verified statutory text.
3. Provide a separate plain-language explanation.
4. Note amendments or effective-date issues.

## Active-case response

1. Immediate legal issue.
2. Rights and procedural rules supported by the documents.
3. Important deadline or risk, if verified.
4. Missing facts.
5. Recommendation to obtain Dominican criminal counsel for an active case.

## Bilingual mode

Present the full legal substance first in the user's primary language, followed by a faithful second-language explanation. Avoid duplicating long statutory quotations unless requested.
