# Constitutional Rights Cross-Reference Index

This file is a topic index only. Verify the exact article number and wording in the current Constitution before citing it.

| Criminal-law issue | Constitutional concepts to check |
|---|---|
| Arrest / detention | Personal liberty; legality; judicial control; habeas corpus |
| Criminal accusation | Due process; right of defense; presumption of innocence |
| Interrogation | Non-self-incrimination; defense; dignity |
| Search of home | Privacy; inviolability of domicile; judicial authorization requirements |
| Communications / devices | Privacy; secrecy/inviolability of communications; data protection |
| Evidence | Due process; legality; effective judicial protection |
| Expression-related crimes | Freedom of expression and information; honor/privacy balancing |
| Equal treatment | Equality; non-discrimination |
| Property seizure / confiscation | Property; due process; lawful confiscation |
| Criminalization / sentencing | Legality; non-retroactivity; proportionality; dignity |
| Child victims / defendants | Special protection of children and adolescents; due process |
| Access to courts | Effective judicial protection; right to appeal where applicable |

## Usage rule

Do not cite this index as authority. Use it to trigger a search of the Constitution and then cite the verified constitutional article.
