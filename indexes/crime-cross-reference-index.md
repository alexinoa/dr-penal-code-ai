# Crime Cross-Reference Index

This is a retrieval map. Article numbers should be added only after verification against the controlling source.

| Topic | Primary source(s) to search | Secondary cross-check |
|---|---|---|
| Homicide / killing | Current Penal Code | Constitution; CPP; prior Penal Code for historical conduct |
| Bodily injury / assault | Current Penal Code | CPP; special victim-protection laws |
| Domestic / intrafamily violence | Current Penal Code as amended | CPP; child-protection law when minors involved |
| Sexual offenses | Current Penal Code as amended | CPP; Ley 136-03 where minors are involved |
| Harassment / stalking / cyber harassment | Current Penal Code + Ley 44-26 | Ley 53-07 when technology-related conduct is involved |
| Theft / robbery | Current Penal Code | CPP; firearms law when a weapon is involved |
| Fraud / breach of trust | Current Penal Code | CPP; special commercial/financial law where applicable |
| Real-estate fraud | Current Penal Code as amended | Civil/property law if available |
| Cybercrime / unauthorized access | Ley 53-07 + current Penal Code | CPP; Constitution privacy/due-process rules |
| Money laundering | Ley 155-17 | Current Penal Code; CPP; predicate-offense statutes |
| Drug offenses | Ley 50-88 | CPP; Ley 155-17 for laundering/proceeds issues |
| Firearms offenses | Ley 631-16 | Current Penal Code; CPP |
| Human trafficking / migrant smuggling | Ley 137-03 | Current Penal Code; Ley 285-04; CPP |
| Child/adolescent offenses | Ley 136-03 + current Penal Code | CPP and specialized juvenile procedure |
| Public corruption | Current Penal Code | Ley 311-14; Ley 155-17; public-administration statutes |
| Illicit enrichment / false asset declarations | Ley 311-14 | Current Penal Code; Ley 155-17 |
| Police misconduct / investigative powers | CPP + Constitution | Ley 590-16; current Penal Code |
| Prosecutorial authority | CPP | Ley 133-11 |

## Usage

For each topic:
1. Search the primary source.
2. Check amendments.
3. Search the secondary cross-check only if relevant to the facts.
4. Add article numbers to this index only after verification.
